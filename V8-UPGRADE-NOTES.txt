MAC TESTING
1. Double-click RUN-WEBSITE.command.
2. If macOS blocks it, right-click the file and choose Open.
3. Open http://localhost:3000 in the browser.

For real CRM lead testing, copy .env.example to .env.local and add the same
server-side CRM environment values used by the live website. Never upload a
real .env.local file or secret key to GitHub.
